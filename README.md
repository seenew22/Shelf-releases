# Shelf

복사한 것을 쌓아두고 다시 꺼내 쓰는 macOS 메뉴 바 앱입니다.
텍스트와 이미지, 파일과 폴더를 모두 기억하며, 목록에서 클릭하면 클립보드로 되돌리고
끌어내면 다른 앱에 진짜 파일로 떨어집니다. 모든 데이터는 그 맥 안에만 저장되며
서버와 통신하지 않습니다.

여기는 **내려받는 곳**입니다. 소스는 공개하지 않습니다.

## 요구 사항

| | |
| --- | --- |
| 운영체제 | **macOS 14 (Sonoma) 이상** |
| 기기 | 애플 실리콘, 인텔 맥 모두 |

**macOS 13 이하에서는 설치되지 않습니다.** 창을 다루는 방식과 로그인 항목 등록이
14부터 들어온 기능을 쓰기 때문이며, 우회할 방법이 없습니다. 지금 버전은
`사과 메뉴 → 이 Mac에 관하여` 에서 확인하실 수 있습니다.

## 내려받기

**터미널 한 줄이 가장 간단합니다.** 받아서 설치까지 하고, **경고 화면이 아예 없습니다.**

```bash
curl -fsSL https://raw.githubusercontent.com/seenew22/Shelf-releases/main/install.sh | bash
```

같은 명령을 다시 실행하면 최신 버전으로 갱신됩니다. 브라우저로 받은 파일에만 macOS 가
격리 표식을 붙이기 때문에, 이 길로 받으면 아래의 허용 단계를 거치지 않습니다.

터미널을 쓰지 않으시면 [가장 최근 릴리스](https://github.com/seenew22/Shelf-releases/releases/latest)에서
**`Shelf-….dmg`** 를 받으시면 됩니다.

1. 받은 파일을 엽니다
2. 창이 열리면 `Shelf` 를 옆의 **응용 프로그램** 폴더로 끌어 넣습니다
3. 응용 프로그램 폴더에서 더블클릭합니다

같이 올라와 있는 `.zip` 은 앱이 스스로 갱신할 때 쓰는 파일입니다. 직접 받으실 필요는
없습니다.

### 처음 열 때 한 번 막힙니다

정식 서명을 받지 않은 앱이라 macOS 가 한 번 막습니다. 앱이 손상된 것이 아니라 만든
사람을 확인할 수 없다는 뜻입니다. 한 번만 허용해 주면 다음부터는 그냥 열립니다.

1. `시스템 설정` → `개인정보 보호 및 보안` 을 엽니다
2. 아래로 내리면 `"Shelf"이(가) 차단되었습니다` 라는 줄이 있습니다
3. **`그래도 열기`** 를 누르고, 관리자 암호를 입력합니다

예전 macOS 에서 쓰던 "우클릭 후 열기" 방법은 Sequoia 부터 막혔습니다. 위의 시스템
설정 경로가 유일한 방법입니다.

## 쓰는 법

메뉴 바에 트레이 모양 아이콘이 생깁니다. 무언가를 복사하면 거기 쌓입니다.

| 동작 | 방법 |
| --- | --- |
| 히스토리 열기 | `⌘⇧V` (마우스 커서 옆에 열립니다) 또는 메뉴 바 아이콘 |
| 검색 | 창을 열면 바로 타이핑 |
| 다시 복사 | 항목 클릭 |
| 다른 앱으로 보내기 | 항목을 끌어다 놓기 |
| 여러 개 고르기 | 길게 누르거나 `⌘` 누른 채 클릭 |
| 위에 고정 | 마우스 올린 뒤 압정 버튼 |
| 화면 가장자리로 열기 | 톱니바퀴에서 켜면, 화면 끝에서 잡아 뺄 수 있습니다 |

스크린샷은 `⌘⇧5` 의 저장 위치를 `클립보드` 로 맞춰 두시면 찍는 대로 여기 모입니다.
나중에 여러 장을 골라 한 번에 끌어다 놓으면 됩니다.

## 새 버전

톱니바퀴 → **`새 버전 확인`** 을 누르면 스스로 받아서 갱신합니다.
두 번째부터는 허용 화면도 나오지 않습니다.

## 알아 두실 것

- **정식 서명을 받지 않은 앱입니다.** 처음 열 때 한 번 허용해 주셔야 합니다. 위의 안내를
  봐 주세요.
- **`⌘⇧V` 가 다른 앱과 겹치면 그 단축키만 동작하지 않습니다.** 메뉴 바 아이콘으로는
  그대로 열립니다. 조용히 실패하므로 안 될 때는 이 경우를 먼저 의심해 보세요.
- **히스토리는 이 맥에만 저장되고 어디로도 전송되지 않습니다.** 기기끼리 동기화하지도
  않습니다. 다만 같은 애플 계정이면 유니버설 클립보드로 넘어온 것도 쌓입니다.
- **앱이 꺼져 있는 동안 복사한 것은 남지 않습니다.** 톱니바퀴에서 `로그인할 때 함께 켜기`
  를 켜 두시는 편을 권합니다.
- **비밀번호 관리자에서 복사한 것은 저장하지 않습니다.** 민감한 내용임을 알리는 표식이
  붙어 있으면 아예 읽지 않고 건너뜁니다.
